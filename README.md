# Basic Calculator

A simple and interactive **Basic Calculator** developed using **HTML, CSS, and JavaScript**.

The calculator performs fundamental arithmetic operations such as addition, subtraction, multiplication, and division through an interactive calculator interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal number support
- Delete button
- Clear (AC) button
- Interactive calculator-style interface
- Responsive design for mobile and desktop screens
- Error handling for division by zero

## Technologies Used

- **HTML5** – For creating the calculator structure
- **CSS3** – For styling and responsive design
- **JavaScript** – For calculations, functions, and conditional logic

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Enter numbers using the calculator buttons.
5. Select the required arithmetic operation.
6. Press `=` to display the result.
7. Use **AC** to clear the calculator.
8. Use **DEL** to remove the last entered digit.

## Working

JavaScript functions are used to perform the arithmetic calculations. Conditional statements such as `if-else` are used to determine which operation has been selected.

The calculator uses DOM manipulation to update the display dynamically whenever the user enters a number or performs an operation.
